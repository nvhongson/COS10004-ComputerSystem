# COS10004 - Computer Systems #

COS10004 – Computer Systems (Swinburne University)

Credit (65) – Semester Project

This repository showcases my work for COS10004 – Computer Systems at Swinburne University. The unit explored how computer systems operate at both hardware and software levels, including binary logic, data representation, assembly language, and low-level C programming.

Most of the tasks were completed independently and demonstrate a solid grasp of system architecture, memory management, and bitwise operations. This work forms part of my technical foundation and personal portfolio.
